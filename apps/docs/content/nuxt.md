---
title: Nuxt
description: Run selfix in a Nuxt app with Nuxt UI.
---

A Nuxt app needs no selfix config. Two points matter: the theme is generated by `nuxt prepare`, and your own auto-imported components are protected only when you name them.

## Run the check

From the app root, prepare Nuxt, then check:

```sh
pnpm exec nuxt prepare && pnpm exec selfix
```

Use the same order in CI. Prepare again after you change `ui.theme.colors` or upgrade Nuxt UI. selfix cannot generate the Nuxt UI theme or notice that it is stale.

`nuxt prepare` writes these files, and selfix reads them:

- `.nuxt/ui.css`, the theme with your color aliases.
- `.nuxt/ui/*.ts`, the variants of every component, such as the sizes of `UButton`.

## Optional settings

```ts
import { defineConfig } from "selfix"

export default defineConfig({
  // Set these only when your app differs from the defaults.
  prefix: "Ui", // ui.prefix in nuxt.config.ts
  buildDir: ".nuxt-custom", // buildDir in nuxt.config.ts
  // Protect your own components next to Nuxt UI's.
  components: ["^App[A-Z]"],
})
```

- `prefix` must match the Nuxt UI prefix, or no component is recognized.
- `components` patterns match the name Nuxt registers, such as `AppCard` for `app/components/app/Card.vue`.
- In a layer or a monorepo, run selfix from the app that has `.nuxt`.

## Verify

Add `class="p-4"` to a `UButton` and run selfix on that file. It reports `no-restyle`. If it prints `Nuxt UI was not found`, see [Troubleshooting](troubleshooting.md#nuxt-ui-was-not-found).

The [integration check](maintaining.md#integration-verification) tests this setup against pinned Nuxt and Nuxt UI versions.
